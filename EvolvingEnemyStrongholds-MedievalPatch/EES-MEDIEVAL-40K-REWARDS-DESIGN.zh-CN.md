# EES 中世纪、Medieval Kingdoms 与 40K 奖励整合设计

## 1. 文档范围与状态约定

本文依据当前 RimWorld 1.6 模组文件和本地补丁源码，说明 Evolving Enemy Strongholds（EES）在中世纪环境中的现状，并提出下一轮可实施的 40K 护甲与任务设计。

本文使用三种状态：

- **已实现**：当前补丁已经执行，可由源码或 XML 直接确认。
- **设计建议**：技术上可行，但当前没有写入 EES 奖励或任务代码。
- **不建议**：能够实现，但会破坏稀有度、平衡或中世纪据点的美术一致性。

本文不实施奖励池和任务修改。文中所有 40K 装备均按本轮限制处理：只考虑护甲、头盔、肩甲等穿戴物；若以后加入武器，也只允许少量近战武器，不加入枪械或其他远程武器。

## 2. 当前 EES 中世纪适配

### 2.0 城市核心与等级叠加原则

EES 等级不复制城市模板。KCSG 先按阵营选择一份文化核心模板；EES 再依据 `StrongholdData.tier` 叠加外围城墙、防御节点、房屋/功能区、驻军和金库。T1-T13 映射为 7 个内容档：T1-T2、T3-T4、T5-T6、T7-T8、T9-T10、T11-T12、T13。升级只增加外围和功能密度，核心街区、城门方向和文化材质保持稳定。

该边界保证法国、拜占庭、神罗等模板的辨识度不会被 EES 高等级覆盖；中世纪适配仍使用石墙、木栅栏和中世纪地面。40K 视觉只允许出现在地下、密封军械库或内堡奖励区。

### 2.1 据点成长

**已实现。** 每个普通敌对 `Settlement` 都按 Settlement ID 保存独立的 `StrongholdData`。中世纪据点首次纳入 EES 时从 T1-T3 稳定随机起步，随后按顺序研究、玩家财富、经过时间和自由殖民者人数重新评估，只升不降，最高 T13。研究仍是主值；120 天、200000 财富和 18 名殖民者三项补量合计最多 0.15，第五研究门槛典型约 T12，最终秘银研究才保证 T13。

EES 外围扩张在 T1/T2 为 0 格、T3 为 1 格，之后逐级增加至 T13 的 26 格。中世纪 EES 增援采用总槽位上限 `10 / 15 / 19 / 24 / 30 / 36 / 42 / 48 / 54 / 60 / 66 / 72 / 78`；计算包含地图上已有同阵营 Pawn 和预留指挥官，只截断 EES 新生成的额外 Pawn，不删除阵营原生守军。人员装备仍由各阵营实际 PawnKind 决定，本轮不做高风险的全局品质重抽。

后期人员质量采用受控增强：已经抽中 EES 原生第一精英队的 T11/T12/T13 中世纪据点，分别有 20%/35%/55% 的稳定概率再拆出一支 3-4 人精英队。两队使用独立 Lord 和不同防守点，但都来自同一批已受总槽位上限约束的驻军，不额外增加地图 Pawn；普通守军装备仍不重抽。

十三个外部等级映射到七个内容档：

| EES 等级 | 内容档 | 主要新增内容 |
| --- | ---: | --- |
| T1-T2 | 1 | 补给点、监牢 |
| T3-T4 | 2 | 黑市、灵能祭坛 |
| T5-T6 | 3 | 贵族庄园 |
| T7-T8 | 4 | 指挥要塞 |
| T9-T10 | 5 | 更高规模、驻军和防御密度 |
| T11-T12 | 6 | 后期规模与奖励档 |
| T13 | 7 | 超级要塞、最高档金库 |

默认炮台密度下，T1-T13 的中世纪直射防御数量为：

`0 / 2 / 3 / 4 / 6 / 8 / 10 / 13 / 15 / 17 / 19 / 21 / 25`

中世纪分支不生成迫击炮，也关闭通讯室、弹药库和依赖电力的现代设施。EES 对 Medieval Kingdoms 和 VFE Medieval 2 的既有 KCSG 基地采用外围叠加，不替换其文化核心布局。

### 2.2 T5-T13 外墙外观与生命值

墙体不是每级换一次外观或增加一次单格生命。当前实现只在 T9，也就是内容档 5，发生一次明显跃迁；T9-T13 使用同一种高阶墙体，后续难度主要来自地图规模、驻军、炮台和功能区数量。

下表生命值为当前 Def 的基础值乘当前原版花岗岩 `MaxHitPoints = 1.7` 后的理论最终值，实际游戏界面会按整数显示：

| 派系类型 | T5-T8 外墙 | 理论生命 | T9-T13 外墙 | 理论生命 | 额外弱点 |
| --- | --- | ---: | --- | ---: | --- |
| Medieval Kingdoms 及普通中世纪派系 | 花岗岩原版墙 | 约 510 | `DankPyon_CastleWall` | 约 1700 | Bomb x4，Thump x2 |
| VFE2 王国 | 花岗岩原版墙 | 约 510 | `VFEM2_CastleWall` | 约 1275 | Bomb x2，Thump x2；重创后变为可通行矮墙 |
| VFE2 氏族 | 木制 `VFEM2_Palisade` | 约 98 | `VFEM2_CastleWall` | 约 1275 | 木栅栏和城堡墙均为 Bomb/Thump x2 |

基础 Def 数值分别为：原版墙 300、Medieval Overhaul 城堡墙 1000、VFE2 城堡墙 750、VFE2 木栅栏 150；木材生命倍率为 0.65。

### 2.3 是否超出中世纪原设定

**美术上没有超出。** T9-T13 仍然使用石砌城堡墙、木栅栏、石板门和中世纪地面，没有把科幻墙、能量盾或金属舱壁放进 Medieval Kingdoms 城镇。Medieval Kingdoms 的法国、伊比利亚、拜占庭等文化底图仍是第一视觉主体，EES 只在外围和功能区增加防御。

**数值上存在一个需要实测的偏厚点。** Medieval Overhaul 城堡墙约 1700 HP，在严格中世纪环境缺少现代爆破手段时会明显拖慢攻城。不过该墙原生具有 Bomb x4、Thump x2 的攻城弱点，并非无弱点纯堆血。现阶段不建议先行削弱，应该先用实际 T9、T11、T13 攻城耗时判断。

**不建议**让 T13 改用 40K 科幻墙。更合适的后期视觉升级是增加双层城防、城门楼、塔楼、旗帜、内堡和分区纵深，而不是继续提高单格 HP 或改变整座中世纪城镇的材质语言。

## 3. Medieval Kingdoms 当前奖励池

### 3.1 稳定资源

**已实现。** 七套文化城镇库存均使用受限 KCSG 池，公共资源为：

- 肉干、草药
- 白银、黄金、翡翠
- 木材、花岗岩块、铁锭
- Medieval Overhaul 基础零件
- 亚麻、丝绸
- `Plasteel`，在当前 Medieval Overhaul 体系中作为秘银使用

每个文化池还带两件对应文化的 Tasty 装备。`fillStorageBuildings = false`，`stockpileValueMultiplier = 0.75`，因此不会把每个空储物格全部填满。

这里的“稳定”是指每座文化城镇都有可用的中世纪资源候选池，并且现代物资会被替换为中世纪等价物；不是指上述每一种资源在每座据点都固定必出。若要实现真正的保底资源，下一轮需要另加按等级生成的固定保底包，而不能只依赖 KCSG 随机库存。

### 3.2 现代战利品替换

**已实现。** EES 金库和功能区中的现代战利品会替换为中世纪资源，例如工业组件转为基础零件、高级组件转为黄金、钢铁转为铁锭、工业药转为草药、生存食品转为肉干、超织物转为丝绸；官方超中世纪物品按市值转为黄金。中世纪 CE 弹药奖励被关闭。

### 3.3 文化惊喜装备

**已实现。** 仅 13 个精确白名单内的 Medieval Kingdoms NPC 派系会在 EES 金库中追加文化装备：

| EES 等级 | 单件出现率 | 最大件数 | 品质概况 |
| --- | ---: | ---: | --- |
| T1-T4 | 0% | 0 | 无追加 |
| T5-T6 | 25% | 1 | 劣质或普通 |
| T7-T8 | 40% | 1 | 劣质或普通 |
| T9-T10 | 60% | 1 | 普通或良好 |
| T11-T12 | 80% | 1 | 良好或优秀 |
| T13 | 第一件 100%，第二件 65% | 2 | 优秀 65%、大师 30%、传奇 5% |

因此当前系统已经同时具备常规资源收益和低概率高品质惊喜。T13 文化装备期望数量为 1.65 件，但不是整套装备保底。

当前文化候选池混合了护甲、近战武器和弓弩等远程武器。本轮“只加入护甲，最多少量近战武器”的限制将用于未来 40K 奖励注入；现有中世纪文化战利品本轮不改。如果该限制也要覆盖 Medieval Kingdoms 原有战利品，下一轮必须单独建立护甲/近战白名单，不能直接复用当前四件候选池。

## 4. 当前 40K 中世纪适配的真实边界

### 4.1 Mankind's Finest

**已实现。** `Gear_Acquisition.xml` 移除了 16 个 Mankind's Finest 装备 Def 的制造入口，其中护甲候选包括：

- Mk VII 动力甲与头盔
- Mk X 动力甲与头盔
- Mk X 牧师动力甲与头盔
- Mk I 雷霆战士动力甲与头盔
- 活圣人护甲

补丁也禁造相关枪械和近战武器。当前只有下文明确列出的 Mk VII、Mk X、Mk X 牧师护甲及两件 Astartes 近战武器接入 T11-T13 EES 金库；枪械、雷霆战士、活圣人和唯一角色装备仍不进入该奖励池。

### 4.2 Masters of Mankind 本地移植

**已实现。** 所有 `GW_Rulers_*` 和 `GW_SM_*` 装备制造入口被移除，所有 `GW_*` 的通用 `thingSetMakerTags` 被移除，避免顶级装备意外进入原版通用任务奖励池。

当前已有 `Local_MastersLegendaryArmorCache` 专属任务，权重 1.5，要求：

- 任务点数至少 2500
- 完成 `BEWH_CustodesCreation`
- 完成 `GW_Rulers_MasterForge`
- 地图财富高于 200000
- 自由殖民者多于 7 人
- 18-32 天后过期

任务随机选择一套活圣人、Valdor、帝皇或 Malcador 装备；各套装仍受自己的后续研究条件约束。它不包含普通星际战士护甲，也不包含武器。

### 4.3 当前可确认的护甲 Def

| 建议层级 | 当前存在的护甲 | 说明 |
| --- | --- | --- |
| 普通星际战士 | `BEWH_MkVIIPowerArmor` + 头盔；`GW_Rulers_FirstbornArmor` + `GW_SM_FirstbornHelmet` | 适合后期较常见奖励 |
| 原铸星际战士 | `BEWH_MkXPowerArmor` + 头盔；`GW_Rulers_PrimarisArmor` + 头盔 | 强于普通档，仍可作为非唯一奖励 |
| 精英/重装 | Mk X 牧师套；`GW_Rulers_GravisArmor` + 头盔 | 适合 T13 或高难任务低概率分支 |
| 雷霆战士 | `BEWH_MkIPowerArmor` + 头盔 | 可作为古代遗物主题奖励 |
| 活圣人 | `BEWH_LivingSaintArmor` | 已在专属传奇任务中 |
| 禁军制式外观 | `BEWH_MkXPowerArmor` + 头盔，禁军 Pawn 使用 `(240,170,30)` 金色 | 没有独立禁军 ThingDef；可在专属任务中只复用外观，不改变 Mk X 属性 |

当前已检查的 Mankind's Finest 和本地 Masters 内容中，没有发现一套可直接作为“通用禁军制式甲”的独立 ThingDef。Mankind's Finest 的 `BEWH_CustodesPawn` 实际强制穿戴 `BEWH_MkXPowerArmor` 与 `BEWH_MkXPowerArmorHelmet`，再以 `<apparelColor>(240,170,30)</apparelColor>` 呈现禁军金外观；Valdor 套仍是独立的唯一禁军传奇装备。因此可以复用原版禁军配色，但不能把重染 Mk X 误称为新的禁军护甲 Def，也不能凭概念名称虚构奖励。

## 5. T11-T13 要塞接入 40K 护甲与近战武器

### 5.1 结论

技术上可行，但**不建议把帝皇、Valdor、Malcador 或活圣人整套直接放进所有 T13 金库**。EES 据点可以反复攻打，不受专属任务的一次性叙事约束；这样会使唯一遗物可刷取，并让现有传奇军械库任务失去意义。

推荐采用“双轨制”：

1. T11-T13 要塞继续提供稳定中世纪资源，并有机会出现普通或精英星际战士护甲，以及更低概率的 Astartes 近战武器。
2. 禁军传奇及人类之主级整套继续由低频、强门槛、定制地图的专属任务提供。

### 5.2 已实现的 T11-T13 白名单与概率

**已实现。** 奖励在 EES 金库生成完成后独立结算，不取代中世纪资源或 Medieval Kingdoms 文化装备。每个 Settlement ID 只结算一次；未命中也会保存结算状态，离图重进不能重新抽取。

| EES 等级 | 护甲概率与候选 | 近战概率与候选 | 品质分布 |
| --- | --- | --- | --- |
| T11 | 35%；Mk VII 身甲或头盔 | 5%；Astartes 链锯剑 | 优秀 85%，大师 15% |
| T12 | 55%；Mk VII / Mk X 身甲或头盔 | 8%；Astartes 链锯剑或动力剑 | 优秀 65%，大师 30%，传奇 5% |
| T13 | 75%；Mk VII / Mk X / Mk X 牧师身甲或头盔 | 12%；Astartes 链锯剑或动力剑 | 优秀 45%，大师 45%，传奇 10% |

每座据点最多生成一个 40K 护甲部件和一件近战武器，不直接保证完整套装，并满足以下条件后才允许抽取：

- 已完成对应的后期研究；
- 据点已通过 EES 的财富、时间和研究成长逻辑达到 T11、T12 或 T13；
- 每个 Settlement 使用保存状态记录是否已经生成过 40K 遗物，防止离图重进刷新；
- 与现有 Medieval Kingdoms 文化装备分开计数，避免同时爆出过多高价值装备。

实际护甲白名单为 `BEWH_MkVIIPowerArmor`、`BEWH_MkVIIPowerArmorHelmet`、`BEWH_MkXPowerArmor`、`BEWH_MkXPowerArmorHelmet`、`BEWH_MkXPowerArmorChaplain`、`BEWH_MkXPowerArmorChaplainHelmet`。实际近战白名单为 `BEWH_AstartesChainsword`、`BEWH_AstartesPowerSword`。代码还会用 `apparel` 和 `IsMeleeWeapon` 做类型复核，不使用显示名称、通用标签或 DefName 前缀扩展候选池。

2026-08-10 验证状态：Release 编译 0 警告、0 错误；EES 补丁与独立军械库任务合计 16 个 XML 均以严格 UTF-8 解析；8 个奖励 Def 在当前 Mankind's Finest 1.6 内容中均唯一存在；游戏已加载到可响应的主窗口，最新 `Player.log` 中本实现相关的程序集、类型、Def 和交叉引用异常均为 0。实际进入 T11、T12、T13 据点检查奖励生成、保存载入和离图重进仍属于游戏内流程验收项。

如果目标是“后期任务里很大概率获得”，更合适的分配是：普通星际战士套件在合格任务中高概率出现，精英套件中概率出现，唯一角色套装只在对应专属任务中出现。这里的高概率应绑定任务资格，而不是让所有普通任务共享高权重。

### 5.3 外观处理

40K 护甲只作为密封军械库、地下遗迹或内堡圣物间中的战利品，不用于替换中世纪外墙，也不让 Medieval Kingdoms 守军普遍穿戴。这样可以保留“中世纪城堡里发现失落科技”的惊喜，同时避免法国、拜占庭、西班牙等文化据点整体变成 40K 基地。

可在 T13 内堡增加一个很小的专属军械库房间，但其外部仍使用中世纪城堡材质；40K 视觉只在房间内部的容器、装饰和最终奖励上出现。

## 6. 下一轮任务设计方向

### 6.1 推荐任务梯度

第一任务已完成原型；第二任务“原铸封存库”已实现，后续任务仍为设计建议。

| 任务层级 | 目标地图 | 主要奖励 | 约束 |
| --- | --- | --- | --- |
| 失落战团军械库 | 小型遗迹或废弃堡垒 | Mk VII / Firstborn，较高概率成套 | 后期研究、财富门槛、强守军 |
| 原铸封存库 | 强化遗迹与多段门禁 | Mk X / Primaris，较高概率；Gravis 低概率 | **已实现**：任务点数 5000、财富 400000、10 名自由殖民者、限时、一次性地点 |
| 雷霆战士陵寝 | 古代要塞 | Mk I 套装 | 主题化陷阱与近战守卫 |
| 黄金军械库 | 定制重型要塞 | Valdor、帝皇、Malcador、活圣人；低概率纯近战 | **已实现为第三任务**：三重城防、极高门槛、四天强攻期、一次性状态 |
| 人类之主遗物链 | 多阶段定制地点 | 活圣人、Valdor、帝皇或 Malcador 套 | 世界级门槛、一次性结局 |

所有任务奖励默认只生成护甲部件。若以后允许武器，只给主题明确的近战遗物，并建立显式 Def 白名单；不得用 `thingSetMakerTags` 或宽泛前缀把 40K 枪械重新放回通用奖励池。

| 方案 | 适用性 | 建议 |

## 9. Custom Quest Framework 与 AI/MCP 实施方案

### 9.1 模组定位与使用结论

Workshop `2978572782` 是 **Custom Quest Framework**（包 ID：`HaiLuan.CustomQuestFramework`，下文简称 CQF）。当前检查的 1.6 版本提供任务编辑器、自定义任务地图、Site/WorldObject、Pawn、Duty、Rule、地图生成步骤及地图进出口等运行时能力，适合用于下一轮 40K 高级护甲任务和特定地图制作。

CQF 不具备“直接理解自然语言并自动设计任务”的 AI 功能。正确定位是：**AI 使用 RimSage MCP 查询真实 Def 和源码，以 CQF 的 XML 数据结构生成任务与地图文件；CQF 在游戏中负责载入、生成和运行这些内容。** RimSage 是只读查询工具，CQF 是任务/地图运行框架，文件写入、版本管理和验证仍由 AI 在本地任务 Mod 中完成。

当前 `ModsConfig.xml` 尚未启用 `HaiLuan.CustomQuestFramework`。在开始下一轮实装前需要启用它，并放在 Harmony 之后、本地 40K 任务 Mod 之前。不要直接编辑数字命名的 `2978572782` Workshop 目录；所有生成结果应写入新的本地任务 Mod。若最终任务使用了 CQF 的自定义类，则本地任务 Mod 必须显式声明 CQF 为运行时依赖；若只使用它制作地图、最终能可靠导出为原版/VEF/KCSG 数据，则可以探索去除运行时依赖，但不能预先假设可以脱离 CQF。

### 9.2 已确认可利用的 CQF 能力

| 能力 | 已确认入口 | 40K 任务用途 |
| --- | --- | --- |
| 自定义地图数据 | `QuestEditor_Library.CustomMapDataDef` | 保存军械库、封存库、古代要塞等固定布局 |
| 自定义 Site | `QE_CustomSite`、`CQF_MainSitePart` | 在世界地图生成一次性任务地点 |
| 地图生成 | `GenStep_CustomMap`、`GenStep_MainMap` | 将指定地图数据注入任务地点 |
| 地图进出口 | `CustomMapEntrance`、`CustomMapExit` | 多层遗迹、地下军械库和撤离路径 |
| Pawn 与 Duty | 巡逻、等待、迎战、撤离等 JobGiver/Duty | 设置中世纪守军、机械防卫或主题化近战守卫 |
| 地图编辑工具 | 生成物品、地形、屋顶、路径、阵营、样式、区域导出 | 在游戏内制作原型并转为可维护数据 |
| Rule 文本 | `RuleText` | 任务名称、描述、地点名称及叙事变量 |

CQF 自带的 `Quests/Map/Start.xml` 只是演示数据，不应作为正式任务直接修改。下一轮应先读取 CQF 的实际输出格式，再在本地 Mod 中建立独立命名空间，所有 Def 使用 `Local_EES40K_` 前缀，避免与 CQF、EES、RimDark 和 GrimWorld 冲突。

### 9.3 下一轮 AI + RimSage MCP 工作流

1. 使用 RimSage `search_defs` 搜索原版 `QuestScriptDef`、`SitePartDef`、`MapGeneratorDef`、EES 任务入口、CQF 自定义 Def，以及 RimDark/GrimWorld 的真实护甲 Def。
2. 使用 `get_def_details` 确认候选护甲的继承结果、研究条件、装备部位、制作配方、标签和市场价值；不根据显示名称猜测 DefName。
3. 使用 `search_source`、`read_csharp_symbol` 和 `read_file` 核对 CQF 任务节点、地图数据、奖励生成和存档持久化的实际行为。
4. 为每一档任务先产出任务状态图、地图平面草案、敌人组成、失败条件、奖励白名单和唯一性规则，再写 XML/C#。
5. 所有文件写入新的本地任务 Mod，例如 `Local-EES-40K-QuestPack`；声明对 Harmony、CQF、EES 中世纪补丁以及实际提供装备 Def 的 40K 内容包的依赖或条件加载。
6. 使用静态 XML 解析、Def/XPath 存在性检查、Release 编译和游戏内开发模式逐项验证；每次只根据最新 `Player.log` 的第一条独立异常继续修复。
7. 大改前确认 Git 工作区干净并建立备份提交；不修改数字 Workshop 模组，不直接清洗当前存档。

### 9.5 奖励、唯一性与验收要求

## 10. 本轮结论

当前 EES 中世纪适配已经形成完整的 T1-T13 成长和中世纪化替换；Medieval Kingdoms 同时具有受控的常规资源池和逐级提高概率、品质的文化惊喜装备。T9 以后城堡墙在美术上仍属于中世纪，但 Medieval Overhaul 约 1700 HP 的耐久需要通过真实攻城耗时继续观察。

40K 补丁目前完成的是“不可制造、不可进入通用奖励池、顶级套装由专属任务提供”，尚未把普通星际战士护甲接入 EES。下一轮最合理的方向是让 T13 或后期任务较高概率提供 Mk VII、Firstborn、Mk X、Primaris 等非唯一护甲，同时把活圣人、Valdor、帝皇和 Malcador 保留给低频专属任务。这样既有后期惊喜，也不会破坏中世纪据点外观和传奇装备的唯一性。
